# Cuadrante

[![Code: MIT](https://img.shields.io/badge/Code-MIT-4B4FD1)](LICENSE)
[![Content: CC BY-SA 4.0](https://img.shields.io/badge/Content-CC_BY--SA_4.0-4B4FD1)](LICENSE-CONTENT.en.md)
[![Latest version](https://img.shields.io/github/v/release/dferrandizmont/cuadrante?include_prereleases&label=version)](https://github.com/dferrandizmont/cuadrante/releases)

A shift calendar for people working shifts in Spain: healthcare, police,
firefighters, industry, hospitality or any other field. Set up mornings,
afternoons, nights, on-call shifts and days off, and see your next shift at a glance.

**Entirely free, no ads, no accounts, offline. Open source.** All available
features are included, with no Pro tier or in-app purchases. Android is in
testing; iPhone is coming soon. Light and dark themes.

## Downloads

- **Android: Google Play closed test.** Two steps, in this order and with the same Google account:
  1. Join the [cuadrante-testers](https://groups.google.com/g/cuadrante-testers) group.
  2. Opt in to the test on [Google Play](https://play.google.com/apps/testing/es.cuadrante.app) and install the app from there.
- **iPhone: App Store (coming soon).**
- **Android: direct APK on [GitHub Releases](https://github.com/dferrandizmont/cuadrante/releases/latest).** You have
  to allow installing apps from unknown sources. It is signed with a different key from the Google Play version, so one
  does not update the other: to switch, first export a `.cuadrante` backup from Settings.

## Features

- Monthly **Grid or List**, annual view, agenda and daily notes. Every shift
  has a colour, code and times; List view shows full schedules.
- **Paint shifts** by tapping or dragging, select multiple days, work double
  shifts, copy and paste, undo and redo. Edit shift types, colours, icons and times.
- **Rotations** with a wizard and preview: rotating morning/afternoon/night,
  24/72, 4×4, 6×4, 5×2, 2-2-3 and your own patterns.
- **Multiple calendars**, with no limit, and comparison between two rosters.
- **Spanish public holidays**, with national and regional dates included offline;
  local dates for supported municipalities, plus your own holidays.
- **Alarms per shift type** and note reminders. Timing depends on system
  permissions and restrictions.
- **Android home-screen widgets** for your shifts. The iPhone widget (WidgetKit)
  is pending development on the Mac.
- **Automatic local backups**, export to `.cuadrante`, a restore preview and
  “Test restore”.
- **Import** LRHSoft `.Shifter` backups, `.ics` or CSV files and phone calendar
  events, reviewing the proposed shifts before saving.
- **Hours summary** for worked, night and public holiday hours, overtime and
  early leave; estimated earnings from hourly rates and fixed shift allowances.
- One-off export to the phone calendar, and images of the month and year.
- **Five languages:** español, català, galego, euskara and English. Language
  picker, screen-reader support, larger text and shifts that never rely on colour alone.

## Privacy

Shifts and settings are stored on your phone. No server of ours, analytics,
tracking or crash-report uploads. The app requests **calendar** permission when
importing or exporting, and **notification and alarm** permissions when enabling
reminders. It does not request location, contacts, camera or microphone access.

Google or Apple system backups can include your data, including absences.
Exporting to a synced calendar or sharing a backup sends data to the destination
you choose. The `.cuadrante` file is not encrypted.

## Build and test

Requirements: **Flutter 3.47.7**, Android SDK for Android, or macOS with Xcode
for iPhone. The app uses Riverpod, go_router and Drift for state, navigation
and the local database.

From the repository root:

```bash
cd app
flutter pub get
flutter gen-l10n
flutter analyze
TZ=Europe/Madrid flutter test
```

Offline, use `flutter pub get --offline` with previously downloaded packages.
On Windows, use the system's Madrid time zone (`Get-TimeZone`) and run
`flutter test` without setting `TZ`; the Linux IANA identifier changes time
handling in the Windows runtime.

To build an APK using real storage, without demo data:

```bash
flutter build apk --release --dart-define=USE_DEMO_DATA=false
```

Prepare the public selection using the [exporter](tool/publish/LEEME.en.md).
Signing and publishing require separate preparation and review. Generated files are checked in;
after changing Drift, freezed or JSON sources, run `dart run build_runner build`.
